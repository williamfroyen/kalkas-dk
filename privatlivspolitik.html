Privatlivspolitik

Privatlivspolitik

Kalkas værner om dit privatliv. Hjemmesiden er udformet, så den kan bruges, uden at Kalkas aktivt indsamler personoplysninger om dig.

1. Personoplysninger

Kalkas indsamler, gemmer eller analyserer ikke personoplysninger såsom navn, e-mailadresse eller andre kontaktoplysninger via hjemmesiden.

2. Cookies og sporing

Hjemmesiden bruger ingen cookies, analyseværktøjer, annonceringsværktøjer eller anden teknologi til at spore besøgende.

3. Drift og tekniske oplysninger

Hjemmesiden hostes via GitHub Pages. Når du besøger hjemmesiden, kan GitHub behandle tekniske oplysninger såsom din IP-adresse for at levere og beskytte tjenesten. Kalkas bruger ikke disse oplysninger til analyse, profilering, markedsføring eller sporing.

Du kan finde flere oplysninger om GitHubs behandling af personoplysninger i GitHubs privatlivspolitik: GitHub General Privacy Statement .

4. Tredjeparter

Kalkas sælger ikke personoplysninger og deler ikke personoplysninger med tredjeparter med henblik på markedsføring, annoncering eller analyse. Tekniske oplysninger kan behandles af GitHub i forbindelse med drift og sikkerhed på hjemmesiden.

5. Dine rettigheder

I henhold til GDPR har du, i det omfang personoplysninger om dig behandles, blandt andet ret til at anmode om oplysninger om behandlingen og i visse tilfælde anmode om indsigt, berigtigelse eller sletning.

Du har også ret til at indgive en klage til den relevante tilsynsmyndighed, eksempelvis Datatilsynet i Danmark, Integritetsskyddsmyndigheten (IMY) i Sverige eller Datatilsynet i Norge.

6. Kontakt

Den dataansvarlige for den behandling, som Kalkas er ansvarlig for, er:

  • Navn: William Frøyen

Hvis du har spørgsmål om denne privatlivspolitik eller behandlingen af personoplysninger, er du velkommen til at kontakte os.

7. Ændringer i privatlivspolitikken

Vi kan opdatere denne privatlivspolitik, hvis hjemmesidens funktioner eller behandlingen af personoplysninger ændres. Den seneste version er altid tilgængelig på denne side.
